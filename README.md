# 國中二年級社會探究評量站

學生公開入口：https://janeykases-cloud.github.io/social-assessment-grade8/

包含地理、歷史、公民共 10 份評量、261 題。每卷滿分 100 分，保留原卷圖表，提供即時正誤回饋與逐題引導。首次作答計分，訂正另計。

學習進度與成績保存於學生目前瀏覽器，支援 CSV 下載；不自動集中回傳教師端。適合形成性評量與自主練習。

## 維護

由 main 分支根目錄透過 GitHub Pages 發布。直接更新 index.html、style.css、app.js、data.js 及 assets/ 後會重新發布。

依教師版答案改編；部分原卷措辭已在對應題目的引導中補充提醒。
